This repository contains data about socialist Yugoslavia's contacts and relations with political organizations abroad, produce within the ERC project [Brokers-of-NAM.](https://github.com/DARIAH-SI/Brokers-of-NAM)

The current contents are:

1. A CSV file with data on socialist organizations and liberation movements that were in contact with Yugoslavia in the 1950s.
